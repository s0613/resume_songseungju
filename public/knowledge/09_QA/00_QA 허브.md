# QA 허브

> 09_QA 진입점. **01은 원리(판단 기준), 02는 테스트 전략, 03은 결함·검수**다.
> 코드 레벨 테스트 작성법은 [[백엔드 테스트 실전]]·[[프론트엔드 테스트 실전]]이 정본이고, 검수 시나리오 문서 자체의 작성법은 [[시나리오·예외사항 문서 작성법]](02_기획) — 여기는 품질 활동 전체의 지식이다.

## 01_원리 — 판단 기준

- [[QA 원리]] — 결함 군집·회귀 범위·스모크·탐색적 테스트·자동화 경제학
- [[디버깅 원리]] — 재현 먼저·최근 변경·이분 탐색·가설-검증 루프

## 02_테스트 — 무엇을 어떻게 검증하나

- [[테스트 전략 실전]] — 자원 배분·행동 테스트·테스트 모양·플레이키·LLM 산출물
- 코드 레벨 짝: [[백엔드 테스트 실전]] (06_백엔드) · [[프론트엔드 테스트 실전]] (05_프론트엔드)

## 03_결함·검수 — 발견에서 종결까지

- [[결함 관리 실전]] — 결함 수명주기·심각도 트리아지·하자 vs CR 구분
- [[검수·UAT 대응 실전]] — 발주사 검수 운영: 환경·데이터 준비·분류·검수 완료 조건
