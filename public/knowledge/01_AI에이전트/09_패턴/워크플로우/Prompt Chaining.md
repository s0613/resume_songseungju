# Prompt Chaining

> 한 줄 정의
> 작업을 순차 단계로 쪼개, 각 LLM 호출의 출력을 다음 호출의 입력으로 넘기는 가장 단순한 워크플로우 패턴. Anthropic "Building Effective Agents"의 기본 패턴이다.

## 흐름

```
입력 → LLM 1 → [게이트] → LLM 2 → [게이트] → ... → 출력
```

각 단계 사이에 **게이트(검증)** 를 두어, 중간 결과가 기준을 통과해야 다음 단계로 넘어가게 할 수 있다.

## 언제 쓰나

- 한 번에 풀기엔 복잡하지만, **고정된 하위 단계로 깔끔히 분해**되는 작업.
- 예: 개요 작성 → 검토 → 본문 작성, 또는 번역 → 현지화 다듬기.

## 트레이드오프

- 단계를 나눌수록 각 호출이 단순해져 **정확도↑**.
- 호출이 늘어 **지연↑**. 정확도와 지연의 교환.
