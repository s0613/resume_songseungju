# Adaptive RAG

> 한 줄 정의
> 질의의 **복잡도를 먼저 분류**해, 그에 맞는 검색 전략(검색 없음 / 단일 검색 / 다단계 반복)을 선택하는 RAG. (2024)

## 핵심 아이디어

모든 질문에 같은 양의 검색을 쓰는 건 비효율적이다.

- "프랑스 수도는?" → 검색 불필요(파라미터 지식).
- "A사 최신 분기 매출은?" → 단일 검색이면 충분.
- "A·B·C사를 3개 지표로 비교하라" → 다단계 반복 검색 필요.

Adaptive RAG는 **복잡도 분류기(classifier)** 로 질의를 판별해 비용과 정확도를 균형 맞춘다.

## 라우팅 전략

```
질의 → 복잡도 분류기
        ├─ 단순(사실)     → 검색 생략, 바로 생성
        ├─ 중간(단일 hop) → 1회 검색 → 생성
        └─ 복잡(멀티 hop) → 반복 검색·추론 루프 (→ Agentic)
```

이는 [[Routing]] 패턴을 RAG 진입부에 적용한 것이며, 복잡 분기는 [[Agentic RAG]] · [[Deep Research]]로 이어진다.

## 의의

- **지연·비용 최적화**: 쉬운 질의에 과한 검색을 막는다.
- **정확도**: 어려운 질의에는 충분한 반복을 보장.
- [[Self-RAG]]의 "검색 여부 자가 판단", [[Modular RAG]]의 "흐름 동적 조립"과 같은 흐름의 사고.
