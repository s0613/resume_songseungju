# Agent

> 목표를 받아 스스로 추론하고, 도구를 호출하며, 여러 단계를 거쳐 작업을 수행하는 LLM 기반 자율 시스템.

## 정의

에이전트는 LLM을 추론 엔진으로 삼아 **인식 → 판단 → 행동**을 반복하는 소프트웨어다. 단발성 프롬프트 응답과 달리, 환경(도구·데이터·사용자)과 상호작용하며 목표 달성까지 여러 단계를 능동적으로 진행한다.

구성 요소: LLM(추론), 도구([[Tool]]), 메모리([[Memory Architecture]]), 오케스트레이션 루프.
