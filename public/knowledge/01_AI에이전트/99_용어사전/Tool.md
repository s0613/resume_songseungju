# Tool

> 에이전트가 호출해 외부 작업을 수행하는 함수·API·기능 단위.

## 정의

도구(Tool)는 LLM 자체가 할 수 없는 일—실시간 검색, 계산, DB 조회, 코드 실행, 외부 API 호출 등—을 대신 수행하는 실행 가능한 기능이다. 각 도구는 이름·설명·입력 스키마를 가지며, 모델은 이를 보고 어떤 도구를 어떤 인자로 쓸지 결정한다.

도구 설계 시 읽기/쓰기 분리, 위험 도구 승인 게이트 등 계층화가 안전성에 중요하다.
