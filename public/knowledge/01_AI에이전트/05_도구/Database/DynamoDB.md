# DynamoDB

> AWS가 제공하는 완전관리형 서버리스 NoSQL 키-값/문서 데이터베이스. Amazon이 운영하며 인프라 관리 없이 무제한에 가까운 확장을 목표로 한다.

## 특징
- 키-값 및 문서 모델. 파티션 키(+선택적 정렬 키)로 데이터를 분산 저장한다.
- 한 자리 밀리초 단위의 일관된 지연시간을 대규모 트래픽에서도 유지한다.
- 서버리스로 용량을 자동 조절(온디맨드)하거나 프로비저닝할 수 있고, 글로벌 테이블로 다중 리전 복제를 지원한다.
- TTL, DynamoDB Streams(변경 캡처), 트랜잭션, 보조 인덱스(GSI/LSI)를 제공한다.

## 에이전트에서의 활용
- **세션·대화 상태 저장**: 사용자별 세션, 대화 히스토리, 단기 메모리 등 키 기반 조회가 잦은 상태를 저렴하고 빠르게 보관한다.
- **체크포인트·작업 추적**: 에이전트 실행 단계, 작업 큐, 멱등성 키 등을 저장하는 백엔드로 적합하다.
- **AWS Bedrock 연계**: Bedrock 기반 에이전트와 같은 AWS 생태계에서 서버리스 상태 저장소로 자연스럽게 결합된다.
- 벡터 검색은 기본 제공되지 않으므로 RAG의 벡터 저장은 OpenSearch 등 별도 서비스를 함께 쓴다.

## 장단점
- **장점**: 운영 부담 제로(완전관리형), 자동 확장, 예측 가능한 성능, AWS 통합.
- **단점**: 복잡한 조인·임시 쿼리에 약하고 데이터 모델을 접근 패턴 중심으로 미리 설계해야 한다. 벡터 검색 미지원, AWS 종속.

## 언제 쓰나
- AWS 위에서 대규모·고가용 세션/상태 저장소가 필요하고 운영 인력을 최소화하고 싶을 때.
