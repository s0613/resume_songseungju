# 마케팅 콘텐츠 원리

> 한 줄 정의
> 채널 알고리즘과 사람의 스크롤 행동에서 역산한 콘텐츠 설계 원리. 광고 카피 문구 단위는 [[UX 라이팅 원리]], 검색 유입 설계는 [[SEO 원리]] — 이 문서는 오가닉 콘텐츠의 구조와 운영을 다룬다.

## 3초 훅 법칙 — 첫 줄이 전부

피드에서 콘텐츠의 운명은 첫 1~3초에 결정된다. 스크롤이 멈추지 않으면 본문·CTA·디자인은 **존재하지 않는 것**과 같다. 제작 시간 배분도 이를 따른다 — 본문 다듬기보다 훅 10개 써보고 고르기.

| 훅 패턴 | 구조 | 예 |
|--------|------|----|
| 숫자+결과 | 구체 수치로 성과 제시 | "문구 하나 바꿨더니 CTR 10배" |
| 금지·반전 | 통념을 뒤집는다 | "가입 버튼에 '가입하기'라고 쓰지 마세요" |
| 공감 질문 | 타겟의 고통을 짚는다 | "광고 돌리는데 클릭이 안 나오나요?" |
| 비포/애프터 | 변화를 한 장에 | 개선 전후 소재 나란히 |
| 실수 고백 | 실패담으로 신뢰 확보 | "3개월 광고비를 날리고 배운 것" |

## 채널마다 문법이 다르다 — 복붙이 아니라 번역

같은 메시지도 채널 문법으로 다시 쓴다 (COPE: Create Once, Publish Everywhere):

| 채널 | 소비 맥락 | 우선 요소 |
|------|----------|----------|
| 인스타그램 | 비주얼 스캔, 저장 문화 | 첫 장 훅, 캐러셀(저장 유도형 목록), 릴스 초반 1초 |
| X·스레드 | 텍스트 속독 | 첫 문장이 훅의 전부, 스레드로 깊이 |
| 네이버 블로그 | 검색 유입, 목적 독서 | 검색 의도 매칭, 소제목에 키워드 → [[SEO 원리]] |
| 유튜브 | 클릭 전 판단 | 썸네일+제목이 성과의 절반, 초반 30초 이탈 방어 |
| 링크드인 | 전문성 소비 | 1인칭 경험담 + 업무 인사이트, 외부 링크는 댓글로 |

## 지표의 위계 — 저장·공유 > 댓글 > 좋아요

- 좋아요는 가장 싼 반응이라 신호가 약하다. **저장**(다시 볼 유용함)과 **공유**(정체성 표현)가 알고리즘 가중치도, 실질 의미도 높다.
- 저장을 부르는 형태: 체크리스트, 목록, 템플릿, 비교표.
- 공유를 부르는 형태: "이거 완전 우리 얘기", 소속 집단의 정체성을 대변하는 주장.
- **90-9-1 법칙**: 90%는 눈팅, 9%는 가끔 반응, 1%만 댓글을 단다 — 댓글 분위기로 전체 반응을 판단하지 않는다.

## 일관성 > 바이럴

단발 바이럴은 계정을 키우지 않는다. 주 N회 발행 주기의 **지속**이 알고리즘 신뢰와 구독자 습관을 만든다. 이를 위해:

- 콘텐츠를 재고로 관리한다 — **에버그린**(언제 봐도 유효, 재발행 가능)과 **시의성**(뉴스·트렌드, 유통기한 있음)을 구분해 비율 유지.
- 잘 된 콘텐츠는 6개월 뒤 각도를 바꿔 재발행한다. 팔로워 대부분은 과거 글을 못 봤다.

## 카드뉴스 문법

- **1장 = 1메시지.** 한 장에 두 가지를 말하면 스와이프가 끊긴다.
- 첫 장은 표지가 아니라 **훅**이다 — 제목 장식이 아니라 다음 장을 넘기게 만드는 미끼.
- 마지막 장 = CTA + 저장 유도 ("나중에 보려면 저장").

## 발행 전 검수 게이트

- [ ] 훅: 첫 줄/첫 장만 보고 멈출 이유가 있는가?
- [ ] 단일 메시지: 이 콘텐츠가 말하는 것이 하나로 요약되는가? → [[UX 라이팅 원리]]
- [ ] 채널 문법: 이 채널의 소비 맥락에 맞게 번역했는가?
- [ ] CTA 하나: 팔로우·저장·클릭 중 하나만 요구하는가?
- [ ] 법·윤리: 최상급 표현("최고"·"유일")에 근거 있는가(표시광고법), 외부 글 직접 인용은 출처당 1회·짧게, 과장 없는가?

## 에이전트 적용

- 콘텐츠 생성 에이전트에 5문항 검수 게이트를 자동 스코어링으로 배선 — 최저 항목 리라이트 제안.
- 훅은 1개 생성이 아니라 **N개 생성 → 선택** 구조로 (패턴 표 5종 × 각 2개).
- 외부 레퍼런스 수집 시 인용 한도·재서술 원칙 준수 → [[가드레일]].
