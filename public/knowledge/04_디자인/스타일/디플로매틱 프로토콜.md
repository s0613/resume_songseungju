# 디플로매틱 프로토콜 (Diplomatic Protocol)

> 한 줄 정의
> 대사관·국제기구·전통 협회·공식 행사에 맞춘 의전형 스타일. 깊은 청색, 절제된 브라스 선, 넓은 여백과 대칭축으로 격식을 만든다.

## 언제 쓰나 / 피하나

| 적합 | 부적합 |
|------|--------|
| 대사관·국제회의·공식 초청 | 일상 민원·고빈도 업무 화면 |
| 전통 협회·재단·위원회 소개 | 캐주얼 커뮤니티·유스 브랜드 |
| 의전 행사·연차총회·선언문 | 데이터 탐색·실시간 모니터링 |

## 스타일 DNA

### 팔레트 — 미드나이트 블루 + 브라스 1%

| 토큰 | 값 | 역할 |
|------|-----|------|
| protocol-midnight | `#101E2E` | 주 배경 |
| protocol-navy | `#1C344C` | 보조 면·헤더 |
| protocol-parchment | `#F2EEE4` | 선언문·본문 표면 |
| protocol-brass | `#B49A62` | 1px 선·작은 표식 |
| protocol-ink | `#18212A` | 밝은 면 본문 |
| protocol-mist | `#CBD3D8` | 어두운 면 보조문 |

- 브라스는 금색 버튼이 아니다. **1px 선, 작은 점, 짧은 대문자 라벨**에만 쓴다.
- 그라디언트·광택·금박 효과를 쓰지 않는다. 재료를 흉내 내기보다 색의 절제로 의전을 암시한다.

### 타이포와 리듬

- 영문 표제: Cormorant Garamond 또는 Libre Baskerville. 한글 표제: Noto Serif KR 500~600.
- 본문·내비게이션: Noto Sans KR 400~600. 명조는 선언문·행사명에 집중한다.
- 대문자 영문 라벨은 11~12px, `letter-spacing: .18~.26em`. 한글 자간을 같은 값으로 벌리지 않는다.
- 대칭축을 기본으로 하되 본문은 왼쪽 정렬한다. 읽기까지 의전식 중앙정렬로 만들지 않는다.

### 구조 — 의전의 문법

- 상단 식별부 → 공식 행사명 → 날짜·장소 → 주요 행동 순서. 장식보다 참석자가 필요한 정보를 먼저 둔다.
- 넓은 여백, 중앙 세로축, 얇은 프레임. radius 0, 그림자 없음.
- 로고 자리는 빈 기하학 문장으로 대체하지 않는다. 실제 심벌 사용 권한이 없으면 단순 이니셜·기관명만 쓴다.

## 핵심 레시피 (CSS)

```css
:root {
  --midnight:#101E2E; --navy:#1C344C;
  --parchment:#F2EEE4; --brass:#B49A62; --mist:#CBD3D8;
}
.protocol-hero {
  background:var(--midnight); color:var(--parchment);
  border:1px solid color-mix(in srgb,var(--brass) 60%,transparent);
}
.protocol-kicker {
  font:600 11px/1.2 'Noto Sans KR',sans-serif;
  letter-spacing:.22em; text-transform:uppercase; color:var(--brass);
}
.protocol-title {
  font:500 clamp(2.8rem,7vw,6rem)/1.08 'Noto Serif KR',serif;
  letter-spacing:-.015em;
}
.protocol-rule { width:72px; height:1px; background:var(--brass); }
.protocol-action { border:1px solid var(--brass); border-radius:0; background:transparent; color:inherit; }
```

## 흔한 실수

- 금색 면·그라디언트·광택 → 의전이 아니라 호텔 웨딩홀. 브라스는 1% 이하 선과 표식.
- 가짜 국장·월계수·왕관 → 실제 공신력을 사칭하는 인상. 권한 없는 상징을 발명하지 않는다.
- 전부 중앙정렬 → 초대장 한 장에는 가능하지만 장문 정보는 왼쪽 정렬로 내려온다.
- 얇은 명조 남발 → 작은 화면에서 사라진다. 표제 500+, 본문은 산세리프로.
- 다크 럭셔리와 혼동 → 상품의 욕망이 아니라 기관·행사의 질서가 중심이다. 가격·희소성 언어를 배제한다.
