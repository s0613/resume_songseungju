# 다크 럭셔리 (Dark Luxury)

> 한 줄 정의
> 거의-검정 배경, 얇고 큰 세리프, 금속성 포인트 1%, 넉넉한 여백, 느린 모션 — "비싸 보임"을 어둠과 절제로 만드는 스타일. 소리 지르지 않는 것이 럭셔리의 문법이다.

![[preview-dark-luxury.jpg]]

## 언제 쓰나 / 피하나

| 적합 | 부적합 |
|------|--------|
| 프리미엄 브랜드·부티크·주얼리·위스키 | 밝고 활기찬 대중 제품 |
| 하이엔드 부동산·멤버십·호스피탈리티 | 가격 경쟁 커머스 (어두움이 "비쌈"을 암시해버림) |
| 시니어 톤 포트폴리오·스튜디오 | 텍스트 밀도 높은 문서·도구 UI |

## 스타일 DNA

### 팔레트 — 따뜻한 어둠 + 금 1%

| 토큰 | 값 | 역할 |
|------|-----|------|
| void | `#0C0B09` | 바탕 (순흑 금지 — 따뜻한 거의-검정) |
| ivory | `#EDE6D8` | 텍스트 (순백 금지 — 상아) |
| gold | `#C6A15B` | 포인트 (채도 낮은 금) |
| line | `rgba(198,161,91,.25)` | 헤어라인 괘선·프레임 |

- **금색 면적은 1%** — 괘선·넘버·라벨·호버에만. 금 면적과 럭셔리는 반비례한다(버튼 전체 금색 = 카지노).
- 순흑+순백 대비는 하드 테크가 된다 — 럭셔리의 대비는 따뜻한 어둠 + 상아.

### 타이포

- 디스플레이: 얇은 웨이트의 세리프를 크게 (Cormorant Garamond, Italiana — Light 300을 100px대로). **얇음은 큰 크기의 특권** — 작게 쓰면 가독성 붕괴.
- 라벨: 산세리프 대문자 + 자간 `.25em+` — 이 "간격"이 고급의 절반이다.
- 한글: Noto Serif KR Light. 헤드라인 외 본문은 굵기 한 단계 올려서.

### 장치 (시그니처)

헤어라인 괘선 · 로마숫자·넘버링(No. Ⅳ) · 이미지 얇은 프레임 · 듀오톤/저채도 사진 · 슬로우 모션(500~800ms) · 여백 배율 일반 제품의 1.5~2배.

## 핵심 레시피 (CSS)

```css
.luxe {
  background: #0C0B09; color: #EDE6D8;
  font-family: 'Cormorant Garamond', 'Noto Serif KR', serif;
}
h1 {
  font-size: clamp(44px, 7vw, 120px);
  font-weight: 300; line-height: 1.05;   /* 얇음은 큰 크기에서만 허용 */
}
.label {
  font: 500 11px/1 'Inter', sans-serif;
  letter-spacing: .28em; text-transform: uppercase;
  color: #C6A15B;                        /* 금은 글자와 선에만 */
}
.frame { border: 1px solid rgba(198,161,91,.25); padding: 8px; }  /* 사진 액자 */
.divider {
  height: 1px;
  background: linear-gradient(90deg, transparent, rgba(198,161,91,.5), transparent);
}
img.tone { filter: grayscale(.35) contrast(1.05) brightness(.92); } /* 사진 톤 통일 */
```

- 모션은 느리게(500~800ms ease), 이동은 작게(페이드 + 12px 상승) — 서두르는 것은 럭셔리가 아니다.
- 깊이는 그림자·글로우가 아니라 **여백과 크기 대비**로 만든다. 글로우는 게이밍이다.
- 사진이 절반이다 — 톤 필터 하나로 전체 화보를 묶고, 저품질 이미지는 아예 빼는 게 낫다.

## 흔한 실수

- 금색 면적 과다 (금 버튼·금 배경) → 카지노. 금은 실선과 글자에만.
- 순흑(#000) + 순백(#FFF) → 럭셔리가 아니라 하드 테크 대비.
- 얇은 세리프를 본문 크기에 → 읽히지 않는 멋. 얇음은 디스플레이 전용.
- 빠른 모션 (150~250ms) → 다른 스타일에선 정답이지만 여기선 조급함. 럭셔리는 느긋하다.
- 요소로 가득 채운 화면 → 여백을 살 수 있다는 것이 럭셔리의 신호다. 빼는 것이 디자인.

## 실물 레퍼런스

**정석 — 절제 문법의 원전**
- [Aesop](https://www.aesop.com) — "조용한 럭셔리" 커머스의 교과서. 다크가 아니라 라이트 럭셔리지만, 여백·세리프·저채도·절제라는 뼈대가 같다 — 팔레트만 뒤집으면 이 문서다.
- 명품 하우스 실사이트(까르띠에·롤렉스 등)는 시즌마다 바뀐다 — URL보다 구조(여백 배율·금 면적·모션 속도)를 관찰하라.

**갤러리**
- [Awwwards — Luxury 컬렉션](https://www.awwwards.com/websites/luxury/) — 럭셔리 계열 수상작. 다크·라이트 럭셔리가 섞여 있어 비교 관찰에 좋다.
- [Awwwards — Black 컬렉션](https://www.awwwards.com/websites/black/) — 검정이 지배하는 수상작 모음. Luxury 컬렉션과 겹쳐 보면 "검정이 언제 비싸 보이는가"가 갈린다.
- 세리프 페어링 감각은 [[에디토리얼 매거진]]의 Typewolf 참조.

**기법**
- [Material Design — Dark theme](https://m2.material.io/design/color/dark-theme.html) — 다크 표면 공학의 표준 문서. 순흑 대신 어두운 표면, 밝기로 위계 — 이 문서의 "순흑 금지"가 접근성 원칙이기도 한 근거.

**폰트**
- [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) · [Italiana](https://fonts.google.com/specimen/Italiana) — 얇고 큰 디스플레이 세리프. 라벨: [Inter](https://fonts.google.com/specimen/Inter). 한글: [Noto Serif KR](https://fonts.google.com/noto/specimen/Noto+Serif+KR).

- 검색 키워드: `luxury web design`, `quiet luxury branding`
