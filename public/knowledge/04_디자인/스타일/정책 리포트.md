# 정책 리포트 (Policy Report Editorial)

> 한 줄 정의
> 국책연구원·중앙은행·공공정책 보고서의 조판 문법을 웹으로 옮긴 스타일. 화려함 대신 문서번호·초록·근거·표의 질서로 전문성을 만든다.

## 언제 쓰나 / 피하나

| 적합 | 부적합 |
|------|--------|
| 정책 브리프·백서·연차보고서 | 짧은 전환형 랜딩·이벤트 |
| 연구기관·싱크탱크·ESG 보고 | 조작이 많은 업무용 앱 코어 |
| 근거·각주·표·그래프가 긴 콘텐츠 | 이미지가 주인공인 브랜드 쇼케이스 |

## 스타일 DNA

### 팔레트 — 잉크 + 종이 + 버건디 표식

| 토큰 | 값 | 역할 |
|------|-----|------|
| report-navy | `#1F3349` | 표지·장 제목·차트 주색 |
| report-burgundy | `#7A2E3A` | 권호·핵심 수치·괘선 포인트 |
| report-paper | `#F6F2E9` | 종이 바탕 |
| report-ink | `#24272B` | 본문 잉크 |
| report-muted | `#68717A` | 메타데이터·각주 |
| report-rule | `#B9B2A6` | 괘선·표 경계 |

- 버건디는 면이 아니라 **표식**이다. 페이지 번호·핵심 수치·짧은 괘선 정도로 5% 아래를 유지한다.
- 차트는 네이비 명도 단계 + 버건디 한 색으로 끝낸다. 범례를 무지개로 만들지 않는다.

### 타이포와 조판

- 장 제목: Noto Serif KR / KoPub Batang 계열 600. 본문: Noto Sans KR 또는 읽기 좋은 명조 400 중 매체에 따라 선택.
- 표·각주·메타: 산세리프 12~14px, tabular 숫자. 보고서의 권위는 작은 글자가 아니라 **정확한 정렬**에서 온다.
- 본문 행길이 62~70자, 행간 1.75. 긴 문서에서 전폭 본문은 금지.
- 문서번호 → 제목 → 초록 → 핵심 발견 → 본문 순서를 표지부터 고정한다.

### 구조 — 보고서의 문법

- 상단 20~28%는 표지형 제목 영역, 하단은 초록·핵심 수치·발행 메타의 엄격한 그리드.
- 1px 괘선과 넓은 바깥 여백을 사용한다. 카드 UI보다 페이지·절·표의 개념이 앞선다.
- 표는 세로선 최소화, 헤더 상하선과 행 구분만. 숫자는 오른쪽 정렬, 단위는 열 머리에서 한 번만.

## 핵심 레시피 (CSS)

```css
:root {
  --report-navy:#1F3349; --report-burgundy:#7A2E3A;
  --report-paper:#F6F2E9; --report-ink:#24272B; --report-rule:#B9B2A6;
}
.report-page { background:var(--report-paper); color:var(--report-ink); }
.report-kicker {
  font:600 12px/1.2 'Noto Sans KR',sans-serif;
  letter-spacing:.12em; color:var(--report-burgundy); text-transform:uppercase;
}
.report-title {
  font:600 clamp(2.5rem,6vw,5rem)/1.18 'Noto Serif KR',serif;
  letter-spacing:-.025em; max-width:14ch;
}
.report-section { border-top:1px solid var(--report-rule); padding-top:1rem; }
.report-table th { border-top:2px solid var(--report-navy); border-bottom:1px solid var(--report-rule); }
.report-table td { border-bottom:1px solid color-mix(in srgb,var(--report-rule) 55%,transparent); }
```

## 흔한 실수

- 제목만 명조로 바꾸고 끝 → 보고서성은 문서번호·초록·각주·표 정렬까지 한 시스템일 때 생긴다.
- 본문 12px로 종이 흉내 → 화면에서는 17~18px가 기본. 인쇄 축소 습관을 웹에 가져오지 않는다.
- 모든 섹션을 카드로 감쌈 → 문서가 대시보드가 된다. 페이지·절·괘선으로 나눈다.
- 금색·문장(紋章) 추가 → 정책 전문성과 럭셔리를 혼동한 결과. 권위는 출처와 구조로 만든다.
- 차트색 과다 → 강조할 시리즈 하나만 버건디, 나머지는 네이비 명도 단계.
