# 설계 키트 (인프라 + 개발)

인프라·클라우드·AI 시스템 설계와 **개발 발표·설계도면**에 바로 재사용할 수 있는 Obsidian용 템플릿과 SVG 아이콘 모음이다.

- **인프라/클라우드** 구성도 → `템플릿/Canvas`, `템플릿/Mermaid`(01~06), AWS·AI 아이콘
- **개발 로직·흐름·데이터**(시퀀스·상태머신·ERD·C4·gitGraph·CI/CD 등) → [[10_지식/08_인프라/_설계_키트/템플릿/Mermaid/개발/00_개발_다이어그램_인덱스|개발 다이어그램 인덱스]], `아이콘/개발`
- **발표 장표 구조**(개발 발표 스토리보드) → [[개발 발표 장표 구조]]

## 가장 빠른 사용법

1. `템플릿/Canvas`의 `.canvas` 파일을 복제하고 이름을 바꾼다.
2. Obsidian 파일 탐색기에서 `아이콘` 아래 SVG를 Canvas로 끌어다 놓는다.
3. 연결선에는 **프로토콜·포트 / 인증 / 동기·비동기 / 데이터 분류** 중 필요한 정보를 적는다.
4. 문서 안에 다이어그램이 필요하면 `템플릿/Mermaid`의 코드 블록을 복사한다.

SVG를 노트에 직접 넣는 예:

```md
![[10_지식/08_인프라/_설계_키트/아이콘/AWS_공식_Q2_2026/서비스/Arch_Compute/Arch_Amazon-EC2_64.svg|64]]
```

## 구성

- `템플릿/Canvas`: AWS 3계층, 멀티테넌트 SaaS, AI RAG 설계 초안
- `템플릿/Mermaid`(인프라): 3계층, 멀티테넌트, RAG, 이벤트 기반, 멀티리전 DR, 보안 데이터 흐름
- `템플릿/Mermaid/개발`: 시퀀스, 상태머신, ERD, 플로우차트, C4, gitGraph, CI/CD, 도메인 모델, 유저 플로우, Gantt (10종 + 인덱스)
- `아이콘/AWS_공식_Q2_2026`: AWS 공식 Q2 2026 SVG 862개
- `아이콘/AI`: Gemini, GPT/OpenAI, Claude, Anthropic, Claude Code
- `아이콘/범용`: 사람, 사용자 그룹, 테넌트, 서버, DB, 네트워크, 보안, 운영 등 51개
- `아이콘/개발`: Git, 터미널·코드, 모듈·패키지, 테스트·버그, 리뷰·보안, 빌드·배포, 이슈·이정표 40개
- `아이콘/연결선`: 동기, 비동기, 양방향, 의존성, 복제, 신뢰 경계, 암호화 흐름

## 권장 순서

1. 먼저 [[10_지식/08_인프라/_설계_키트/표기_규칙|표기 규칙]]에서 범례를 정한다.
2. [[10_지식/08_인프라/_설계_키트/아이콘_인덱스|아이콘 인덱스]]에서 자주 쓰는 아이콘을 고른다.
3. 템플릿을 복제해 실제 구성요소·리전·계정·테넌트 경계로 바꾼다.
4. 마지막에 장애 지점, RTO/RPO, 데이터 소유권, 관측 지점을 표시한다.

> [!tip]
> 서비스 아이콘만 나열하지 말고 **계정 → 리전 → VPC → 서브넷 → 워크로드 → 데이터** 순서로 경계를 먼저 그리면 설계 의도가 훨씬 잘 보인다.
