# 출처와 라이선스

## AWS

- 자산: AWS Architecture Icons, Q2 2026 패키지 `Icon-package_04302026`
- 공식 페이지: https://aws.amazon.com/architecture/icons/
- 이 키트에는 원본 중 다이어그램에 유용한 SVG만 정리했다.
  - 서비스 64px: 305개
  - 리소스 48px: 516개
  - 그룹 32px: 15개
  - 카테고리 64px: 26개
- AWS는 고객과 파트너가 아키텍처 다이어그램을 만드는 용도로 이 도구와 자산을 사용할 수 있다고 안내한다. 아이콘을 변형하지 않고 최신 공식 가이드를 따른다.

## AI 브랜드 아이콘

- Gemini, Claude, Anthropic, Claude Code: Simple Icons `16.26.0`
- GPT / OpenAI: Simple Icons `14.x`의 OpenAI SVG
- Simple Icons 라이선스: CC0 1.0. 단, 각 로고의 상표권은 해당 소유자에게 있으며 CC0가 상표권을 허가하지는 않는다.
- 브랜드 원출처:
  - Gemini: https://gemini.google.com/
  - OpenAI: https://openai.com/brand/
  - Claude: https://claude.ai/
  - Anthropic: https://www.anthropic.com/
- 내부 아키텍처 다이어그램에서 실제 사용 서비스를 식별하는 용도로만 사용하고, 제휴·보증을 암시하거나 로고를 변형하지 않는다.
