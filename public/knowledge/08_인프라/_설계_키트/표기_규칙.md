# 인프라 다이어그램 표기 규칙

## 경계

| 경계 | 표현 | 반드시 적을 것 |
|---|---|---|
| 조직/테넌트 | 굵은 실선 박스 | 소유자, 격리 단위 |
| 클라우드 계정/프로젝트 | 실선 박스 | 계정명, 환경 |
| 리전 | 파란 박스 | 리전, DR 역할 |
| VPC/VNet | 초록 박스 | CIDR, 라우팅 책임 |
| 가용영역/서브넷 | 점선 박스 | public/private, CIDR |
| 신뢰 경계 | 빨간 점선 | 인증 방식, 정책 집행점 |
| 데이터 경계 | 보라 박스 | 데이터 등급, 암호화 키 |

## 연결선

| 선 | 의미 | 라벨 예시 |
|---|---|---|
| 파란 실선 화살표 | 동기 요청 | `HTTPS 443 / JWT` |
| 주황 점선 화살표 | 비동기 이벤트 | `OrderCreated v2` |
| 청록 양방향 화살표 | 세션·스트림·동기화 | `WebSocket / mTLS` |
| 회색 점선 화살표 | 논리 의존성·제어 | `deploys`, `assumes role` |
| 보라 이중 화살표 | 복제·백업 | `async replication / RPO 5m` |
| 초록 자물쇠 화살표 | 암호화된 민감 데이터 | `TLS + KMS CMK` |

연결선에는 가능한 한 다음을 순서대로 표기한다.

```text
프로토콜/포트 · 인증/인가 · 동기/비동기 · 데이터/이벤트명
```

## 최소 체크리스트

- [ ] 사용자, 운영자, 외부 시스템이 구분되어 있는가?
- [ ] 테넌트·계정·리전·네트워크·데이터 경계가 보이는가?
- [ ] 인터넷 진입점과 인증/인가 지점이 보이는가?
- [ ] 동기 호출과 비동기 이벤트가 구분되는가?
- [ ] 데이터 원장(source of truth), 캐시, 검색 인덱스가 구분되는가?
- [ ] 암호화 키와 비밀정보의 소유 주체가 보이는가?
- [ ] 로그·메트릭·트레이스와 알람 경로가 보이는가?
- [ ] 재시도, 타임아웃, DLQ, 멱등성 위치가 보이는가?
- [ ] 장애 도메인과 failover 방향, RTO/RPO가 적혀 있는가?
- [ ] 비용이 크게 발생하는 경로와 확장 단위가 보이는가?
