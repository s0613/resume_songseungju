# 승주의 지식 볼트 (공개판)

AI 에이전트와 함께 일하면서 쌓은 실무 지식 노트입니다.
옵시디언(Obsidian) 볼트에서 쓰던 마크다운 파일을 그대로 담았습니다.

## 쓰는 법

1. 압축을 풉니다.
2. 옵시디언에서 `10_지식` 폴더를 볼트로 열거나, 기존 볼트에 통째로 복사합니다.
3. 문서끼리 `[[위키링크]]`로 연결돼 있어 옵시디언에서 열어야 그래프·백링크가 살아납니다.

에디터 없이 그냥 읽어도 됩니다. 전부 평범한 마크다운입니다.
