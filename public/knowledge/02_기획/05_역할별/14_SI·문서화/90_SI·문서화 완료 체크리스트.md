# SI·문서화 완료 체크리스트

## 계약·문서 10종

- [ ] 산출물별 형식·수준·Owner·마일스톤·검수·대금 조건이 있다.
- [ ] 작업 개요, 제안서, 요구사항, WBS, 데모, 결과보고서가 현재 상태다.
- [ ] SLA, 견적서, 주간 보고서, 도메인 맵이 현재 상태다.
- [ ] 10종 문서를 종료 직전에 몰아 쓰지 않고 단계별 원천에서 갱신했다.
- [ ] 확인하지 않은 수치·기능·테스트를 사실처럼 쓰지 않았다.

## 추적·검수

- [ ] 모든 계약 요구가 RTM에서 설계·구현·테스트·발주사 검수로 연결된다.
- [ ] 미구현·미수행·범위 밖·조건부 승인이 드러난다.
- [ ] 검수 대상 버전, 피드백 기간, 재검수·승인 기록이 있다.
- [ ] 결과보고서가 RTM과 실제 QA 결과를 반영한다.

## 매뉴얼·인계·지원

- [ ] 시스템·운영·사용자 매뉴얼이 실제 버전과 일치한다.
- [ ] 발주사가 교육·운영·복구 시나리오를 직접 수행했다.
- [ ] 소스·배포·문서·라이선스·대시보드 자산 인수가 확인됐다.
- [ ] 비밀값을 문서에 적지 않고 안전한 경로로 이전했다.
- [ ] CR·SLA·하자보수·유상 유지보수 경계가 합의됐다.
- [ ] [[99_SI 납품 확인 템플릿]]에 미해결과 조건부 항목까지 기록했다.
