# 고객·업무책임 완료 체크리스트

## UAT·승인

- [ ] 승인된 요구사항과 정확한 대상 버전으로 UAT를 수행했다.
- [ ] 핵심·예외·권한·오류·복구 업무 시나리오에 결과·증거가 있다.
- [ ] QA 결과와 고객 업무 적합성 판정을 혼동하지 않았다.
- [ ] 신규 요구를 결함과 분리해 CR로 기록했다.
- [ ] 조건부 승인에 Owner·기한·재검수·정산 조건이 있다.

## 고객 행동·인수

- [ ] 고객 Owner Action과 외부 의존의 담당·기한·지연 영향이 있다.
- [ ] 소스·문서·데이터·도메인·라이선스·운영 자산을 확인했다.
- [ ] 고객이 운영·권한 관리·장애·복원 시나리오를 직접 검증했다.
- [ ] 임시·수행사 접근의 회수·종료 조건이 있다.
- [ ] 비밀번호·토큰·API 키·인증서·복구코드 값을 문서에 저장하지 않았다.

## 종료 후 책임

- [ ] 하자, 운영 문의, 환경 변화, 신규 개선의 경계가 있다.
- [ ] 지원 채널·시간·심각도·응답·복구 기준을 합의했다.
- [ ] 미해결 항목에 Owner·기한·완료 기준이 있다.
- [ ] [[99_고객 인수 확인 템플릿]]에 대상 버전과 조건을 기록했다.
