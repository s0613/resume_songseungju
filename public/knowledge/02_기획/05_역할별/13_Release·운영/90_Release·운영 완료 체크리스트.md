# Release·운영 완료 체크리스트

## 범위·승인

- [ ] QA가 판정한 버전과 이관 artifact가 일치한다.
- [ ] 이관본이 발주사가 검수(UAT)한 버전과 일치한다.
- [ ] 포함·제외 변경, 의존성, 설정·DB 버전을 manifest로 고정했다.
- [ ] 리뷰·QA·보안·발주사의 차단 항목이 처분됐다.
- [ ] 보호 branch merge를 지정 사람이 승인했다.
- [ ] 운영 환경 이관을 지정 사람이 대상 버전 확인 후 승인했다.
- [ ] 자동화·에이전트를 사람 승인자로 기록하지 않았다.

## 실행·복구

- [ ] 배포·마이그레이션 단계마다 Owner·검증·중단 조건이 있다.
- [ ] 이전 안정 버전과 롤백 트리거가 명확하다.
- [ ] 백업은 복원 시험 결과까지 확인했다.
- [ ] 데이터 변경의 호환성과 되돌림 한계를 승인자가 안다.
- [ ] 비밀값 자체를 문서에 저장하지 않았다.

## 관찰·인계

- [ ] 헬스·오류·지연·핵심 업무 경로·데이터 지표의 임계값이 있다.
- [ ] 온콜·발주사·현업 공지와 에스컬레이션이 준비됐다.
- [ ] 스모크와 합의한 안정화 관찰 창을 통과했다.
- [ ] 이상·롤백·미수행·잔여 위험을 기록했다.
- [ ] 안정화 종료 시점과 하자보수 개시일을 기록했다.
- [ ] [[99_릴리즈 보고 템플릿]]으로 운영 Owner에게 인계했다 — 이 기록이 인수인계서·완료보고서의 근거다.
