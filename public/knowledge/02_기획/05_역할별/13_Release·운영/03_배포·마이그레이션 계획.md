## 완료 확인

- [ ] 승인된 artifact 외 변경이 배포되지 않았다.
- [ ] 스키마와 구·신 애플리케이션 호환을 검증했다.
- [ ] 핵심 사용자 경로와 헬스체크를 실제 환경에서 확인했다.
- [ ] 배포 중 임시 권한·flag·유지보수 모드를 정리했다.
