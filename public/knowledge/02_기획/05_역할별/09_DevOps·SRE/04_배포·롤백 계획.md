# 배포·롤백 계획

> 대상 version, 의존 순서, health 기준, 중단과 복구를 실행 순서로 고정한다. 검수·오픈 배포는 발주사와 합의한 배포 창 안에서 실행하고, 절차는 그대로 시스템(설치)·운영 매뉴얼에 반영한다.

## 완료 질문

- [ ] Database migration과 애플리케이션 version 순서가 합의됐는가?
- [ ] healthcheck가 단순 process 생존이 아니라 핵심 의존성을 반영하는가?
- [ ] 점진 배포와 자동·수동 중단 조건이 수치로 정의됐는가?
- [ ] 같은 artifact로 rollback하며 데이터 호환성을 확인했는가?
- [ ] 검수 환경에 배포된 버전이 검수본(tag·digest)과 일치하는가?
- [ ] 발주사 운영자가 이 절차를 대화 없이 실행할 수 있는가 — 매뉴얼 반영까지가 완료다.
