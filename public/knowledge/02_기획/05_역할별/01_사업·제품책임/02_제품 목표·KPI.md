# 제품 목표·KPI

> 외주에서 목표는 성장 지표가 아니라 **계약 목표와 검수 기준**이다. 착수 전 발주사와 합의된 기준만 유효하다 — 사후 합의는 분쟁 원인. "만족스러우면"은 기준이 아니다 ([[SI 수주와 범위 관리]] §마일스톤).

## 계약 목표 문장

> **{발주사}에 {납품 범위}를 {납기}까지 납품하고, {검수 기준}을 충족해 검수 통과 → 인수인계 → 잔금 → 하자보수 경계 확정까지 완료한다.**

| 항목 | 값 |
|---|---|
| 목표 ID | `{OBJ-001}` |
| Owner | `{한 명}` |
| 발주사 문제·범위 원본 | `[[01_문제·대상사용자 정의]]#{앵커}` |
| 계약 기간 | `{착수일 ~ 종료일}` |
| 검수 예정일·마일스톤 | `{중간검수 / 최종검수 날짜}` |
| 발주사 합의 상태 | `초안 / 발주사 검토 중 / 합의(서명·회의록 링크)` |

## 검수 기준 합의표 (계약 첨부용)

> 이 표가 테스트결과서·검수확인서의 원본이다. 모든 기준은 [[요구사항과 완료 조건]]의 기계 검증 가능 형식 — 실행하면 PASS/FAIL이 나와야 한다.

| ID | 검수 항목 | 판정 기준 (PASS 조건) | 판정 방법·도구 | 판정자 | 연결 마일스톤 | 합의 근거 |
|---|---|---|---|---|---|---|
| `ACC-01` | `{핵심 기능}` | `{시나리오 N건 전부 PASS}` | `{테스트케이스 ID·E2E}` | `발주사 검수자 + QA` | `{검수 마일스톤}` | `{회의록·메일 링크}` |
| `ACC-02` | `{성능}` | `{예: 응답 p95 < 3s, 동시 N명}` | `{부하·측정 도구}` | `{판정자}` | `{마일스톤}` | `{근거}` |
| `ACC-03` | `{데이터·연동}` | `{이관 건수 일치율 100% 등}` | `{검증 스크립트}` | `{판정자}` | `{마일스톤}` | `{근거}` |

- 기계화가 안 되는 항목(디자인 톤 등)은 **판정자와 기준표·수정 라운드 횟수**를 명시한다: "발주사 {누가} {기준표}로 판정, 피드백 {N}회".
- 검수 기간 상한을 계약에 넣는다: `전달 후 {N}영업일 내 피드백 없으면 승인 간주` — 무기한 검수는 잔금 무기한 유예다.

## SLA·비기능 합의

| ID | 항목 | 임계값 | 측정 방법 | 적용 시점 | 미충족 시 처리 |
|---|---|---|---|---|---|
| `SLA-01` | `{가용성}` | `{예: 월 99.5%}` | `{모니터링}` | `오픈 후 / 하자보수 기간` | `{하자보수 범위 / 별도 유지보수}` |
| `SLA-02` | `{장애 대응}` | `{예: Critical 4시간 내 착수}` | `{접수 채널·기록}` | `{기간}` | `{처리}` |

> SLA는 하자보수(무상: 버그)와 유지보수(유상: 개선·신규)의 경계와 함께 합의한다. 경계 없는 SLA는 무상 지원 무한 연장이다.

## 검수 실패·분쟁 예방 규칙

| 상황 | 사전 합의된 처리 | 승인자 |
|---|---|---|
| 검수 FAIL (기준 미달) | `결함 조치 후 재검수 — 재검수 기한 {N}일` | `{이름}` |
| 기준에 없는 신규 요구 | `CR 절차 회부 ([[04_중단·피벗·승인 기준]])` | `{이름}` |
| 발주사 검수 지연 | `{N}영업일 경과 시 승인 간주 + 지연 기록` | `{이름}` |
| 발주사 자료·결정 지연 | `일정 영향 즉시 서면 통지 + 납기 연장 근거로 기록` | `{이름}` |
| 기준 해석 이견 | `합의 근거(회의록·메일) 원본으로 판정, 원본 없으면 CR` | `{이름}` |

## 진행 지표 (내부 관리용)

> 발주사에 보고하는 것은 진행률 %가 아니라 "이번 주 보여줄 수 있는 것 / 다음 주 할 것 / 막힌 것·필요한 결정" 3줄이다. 아래는 내부 조기 경보용.

| 지표 | 정의 | 경보 임계값 | 확인 주기 | Owner |
|---|---|---|---|---|
| 마일스톤 지연일 | `계획 대비 지연` | `{N일 이상 → 발주사 통지}` | `주간` | `{이름}` |
| 미합의 검수 기준 수 | `ACC 중 합의 근거 없는 것` | `착수 시점 0건` | `착수 전·CR 시` | `{이름}` |
| 무상 처리한 범위 밖 요청 수 | `CR 없이 수행한 건` | `0건 초과 시 경보` | `주간` | `{이름}` |
| 발주사 지연 건수 | `자료·결정 지연 기록` | `기록 누락 0건` | `발생 즉시` | `{이름}` |
