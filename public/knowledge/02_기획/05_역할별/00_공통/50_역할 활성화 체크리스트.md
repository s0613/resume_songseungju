# 역할 활성화 체크리스트

> 계약마다 필요한 역할만 고른다. 담당자가 같은 경우에도 역할별 산출물과 판정 시점은 분리한다. 수행사 역할을 고르는 것과 함께 **발주사 측 카운터파트가 실재하는지**를 착수 전에 확인한다 — 검수자·승인자가 없는 프로젝트는 끝낼 방법이 없다.

## 항상 확인 — 수행사 역할

- [ ] **사업·제품 책임 (계약·범위)** — 계약 목표·범위(제외 포함)·수주 Go/No-Go·CR 승인을 결정할 사람이 필요한가?
- [ ] **PM·PO·BA** — 요구 확정·우선순위·검수 기준 합의·발주사 창구 관리를 조정해야 하는가?
- [ ] **QA·Judge** — 구현자의 완료 주장을 독립적으로 판정하고 테스트결과서를 만들어야 하는가?
- [ ] **SI·문서화** — 계약 산출물 목록·RTM·매뉴얼·인수인계서를 책임질 사람이 필요한가? (외주에서는 사실상 항상)

## 항상 확인 — 발주사 측 역할 (착수 전 실명 확인)

- [ ] **발주 담당** — 자료 제공·의사결정·CR 승인의 단일 창구가 지정됐는가? 지연 시 기록·공지 경로가 합의됐는가?
- [ ] **현업 검수자** — 업무 관점에서 검수할 사람이 지정됐고, 검수 기준이 착수 전에 합의됐는가?
- [ ] **최종 승인자 (전결권자)** — 검수확인서 서명·잔금 승인 권한자가 확인됐는가? 검수 기간 상한이 계약에 있는가?

발주사 측과의 연결·승인 관리는 [[00_고객·업무책임 기획 가이드]] 역할이 담당한다.

## 변경 내용에 따라

- [ ] **UX·UI 디자인** — 신규 화면·흐름·콘텐츠가 있어 화면정의서(스토리보드)가 필요한가? 시안 수정 라운드 횟수가 계약에 있는가?
- [ ] **Tech Lead·아키텍처** — 시스템 경계·기술 선택·다중 역할 의존성이 있어 시스템구성도·기능사양서가 필요한가?
- [ ] **Frontend** — 브라우저·앱 UI, 상태 관리, 라우팅이 바뀌는가?
- [ ] **Backend** — API, 도메인 규칙, 외부 연동이 바뀌어 API 정의서가 필요한가?
- [ ] **Database** — 스키마·쿼리·마이그레이션·데이터 이관이 있어 ERD·테이블정의서가 필요한가? (데이터 이관은 범위 포함 여부를 계약에서 확인)
- [ ] **Data·ML** — 데이터셋·평가 기준·모델·추론 계약이 있는가?
- [ ] **DevOps·SRE** — 환경·CI/CD·배포·모니터링이 바뀌어 빌드·배포 스크립트, 시스템(설치) 매뉴얼이 필요한가?
- [ ] **Security·Privacy** — 인증·권한·금전·개인정보·외부 입력이 있는가?
- [ ] **리뷰어** — 코드·설계·문서의 독립 렌즈가 필요한 복잡도나 위험인가?
- [ ] **Release·운영** — 이관·오픈, 데이터 변경, 장애·롤백 위험, 안정화 기간이 있는가?

## 최소 구성 선택

| 계약 유형 | 기본 역할 | 조건부 추가 |
|-----------|-----------|-------------|
| 소규모 수정·SM(유지보수) 건 | PM 역할 + 구현 역할 + QA 역할 + 발주 담당 확인 | UI면 디자인, 배포면 Release. 하자보수 범위인지 유상인지 먼저 판별 |
| 일반 SI 구축 | 계약 책임 + PM/BA + 설계(디자인·기술) + 구현 + QA + SI·문서화 + 발주사 3역할 | 데이터·보안·운영 위험별 전문 역할 |
| 단계 오픈형 (파일럿→베타→가오픈→오픈) | 일반 SI 구축 구성 + Release·운영 | 단계별 검수 기준·마일스톤 지불 조건 분리 |
| 데이터·AI 과제 | 계약 책임 + PM + Data·ML + Backend + QA + SI·문서화 | 개인정보면 Security, 운영 이관이면 SRE |
| 고위험 변경 (금전·규제·대외 연동) | 계약 책임 + Tech Lead + Security + 독립 리뷰 + QA + Release + 발주사 승인 강화 | 규제·법무 검토, 검수 기준에 규제 항목 포함 |

|------|----------------------|--------|-----------------------------|-------------|-------------|
| | | | | | |

- [ ] 선택한 모든 역할이 [[20_RACI 템플릿]]에 반영됐는가? (발주사 3역할 포함)
- [ ] 비활성 역할이 보던 위험을 누가 인수하는지 기록했는가?
- [ ] 한 사람이 여러 역할을 맡을 때 독립 판정 장치를 정했는가? (특히 구현자↔QA, 수행사↔검수)
