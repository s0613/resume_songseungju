## 결정 질문

- [ ] 전송·프레임워크 코드 없이 도메인 규칙을 설명하고 테스트할 수 있는가?
- [ ] 상태 변경의 원자성, race condition, 중복 요청을 다뤘는가?
- [ ] 오류를 silently swallow하지 않고 호출자에게 일관되게 전달하는가?
- [ ] 인증 실패가 사용자 존재 여부나 내부 stack을 누설하지 않는가?
- [ ] 모든 규칙이 기능사양서 항목 또는 승인된 CR에 연결되는가?
