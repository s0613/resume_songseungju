## 완료 질문

- [ ] Database 담당자가 실제 쿼리 패턴과 migration 필요를 확인했는가?
- [ ] 모든 목록 조회에 상한 또는 pagination이 있는가?
- [ ] 외부 호출에 timeout이 있고 무제한 retry가 없는가?
- [ ] secret은 코드·예시·로그에 실제 값으로 남지 않는가?
- [ ] 모든 외부 연동이 계약 범위(포함 목록)에 있는가? 아니면 CR 회부했는가?
