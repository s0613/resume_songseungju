(2) 접근성 — ESC로 패널 닫기, 닫을 때 FAB로 포커스 복귀, 패널이 다시 열릴 때마다 입력창 포커스, 메시지 영역 aria-live="polite" + 키보드 스크롤 가능(tabIndex). (3) 대비 — 기존 팔레트 알파 단계 안에서만 상향: .input 테두리는 gold-faint(0.28) 이상, .panelSub/.typing/placeholder는 cream-dim(0.65) 이상. 새 색상 값 추가 금지. (4) 에러 UX — 429는 "질문이 너무 잦아요…" 전용 문구, 그 외 오류와 구분. 에러 안내 문구는 isError 플래그로 표시해 다음 요청 히스토리에서 제외. 스트리밍 자동 스크롤은 사용자가 하단 근처(80px)에 있을 때만. 전송 직후 즉시 "답변을 쓰는 중…" 표시. (5) 3D 에셋 — public/ai-chat-1c.glb를 gltf-transform CLI로 압축(품질 유지 범위), model-viewer 로드는 requestIdleCallback(폴백 setTimeout 1500ms) 이후, GLB 로드 error 이벤트 시 글리프(✦) 폴백 유지, 로드 완료(load 이벤트) 전까지 글리프를 유지해 깜빡임 제거. (6) 모바일 — 패널 높이 vh를 dvh 기반으로 교체해 가상 키보드에 입력창이 가려지지 않게.
